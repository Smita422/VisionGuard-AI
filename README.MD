
# VisionGuard AI

VisionGuard AI is an AI-powered industrial safety monitoring system
that uses Computer Vision and Deep Learning to detect unsafe situations
in industrial environments.

## Current Progress

### Milestone 1 - Basic Object Detection

Implemented basic object detection using YOLO.

The system can:

- Load a pretrained YOLO model
- Process an image
- Detect objects
- Identify object classes
- Display confidence and bounding boxes

## Technologies Used

- Python
- YOLO
- Ultralytics
- OpenCV
